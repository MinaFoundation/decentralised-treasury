## Full Developer Path

If the codebase is new to you, use this order:

1. Read the [Developer overview](overview.md).
2. Read the three foundation pages.
3. Complete the [local development quickstart](local-development/quickstart.md).
4. Select a [development network mode](local-development/network-modes.md).
5. Read the [system architecture](architecture/system-overview.md).
6. Run the [full local blockchain demo](local-development/full-local-demo.md).
7. Select the applicable application, package, or provable-layer page.
8. Use the [testing guide](testing.md) before you submit a change.

The [User section](../learn/index.md) explains Treasury participation. The
[Operator section](../operate/index.md) explains production operation and
incident response. It also contains the Compose live-testnet deployment path.
