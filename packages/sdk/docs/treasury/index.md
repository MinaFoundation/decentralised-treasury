# Treasury Overview

The Mina decentralized treasury is a shared funding process. A treasury holds funds, people submit proposals for work that should be funded, the community reviews those proposals, voters make a decision, and approved proposals can be paid.

Think of the treasury as a public decision room with a clear calendar. There is time to submit ideas, time to review them, time to vote, and time to carry out approved decisions. The website helps participants see where each proposal is in that journey. The command line helps maintainers and operators perform actions that are not yet part of the website.
