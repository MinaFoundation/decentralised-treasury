# Demo Treasury Proposal

## Summary

This proposal requests a demo treasury payout to fund local development and end-to-end testing of the decentralized treasury stack.

## Purpose

The requested funds will be used to:

- exercise the proposal creation, voting, tally, and execution flow
- validate API and web integrations against a realistic treasury proposal
- provide a reusable example for local-blockchain demonstrations

## Rationale

Running a full proposal lifecycle with a concrete proposal body helps verify that:

- proposal content hashing is stable
- proposal indexing and search work correctly
- processor projections reflect lifecycle transitions as expected

## Success Criteria

This proposal is considered successful if:

- the proposal is created on-chain
- votes can be submitted and tallied successfully
- the approved payout can be executed to the configured recipient
